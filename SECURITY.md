# Security Policy

This repository is a research testbed, not a production defence communications system. The Docker network, smart-contract artifact, validator keys, and benchmark scripts are for disposable local experiments only.

Do not report real operational data, credentials, private keys, or sensitive defence information in GitHub issues or pull requests. If a real secret is exposed, revoke or rotate it immediately and remove it from the repository history; deleting the working-tree file alone is not sufficient.

For a code-level issue, open a private report through the repository host's security advisory workflow when available. Otherwise contact the repository owner privately before public disclosure.
